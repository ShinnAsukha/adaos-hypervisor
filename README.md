# OXware Hypervisor — Web Assets

This is the **gh-pages branch** serving:

- [`oxware.top/`](https://oxware.top/) — landing page (`index.html`)
- [`oxware.top/docs/`](https://oxware.top/docs/) — documentation
- [`oxware.top/install.sh`](https://oxware.top/install.sh) — one-line bootstrap installer

## Quick Install

```bash
curl -sSL https://oxware.top/install.sh | sudo bash
```

The bootstrap script clones the main repository to `/opt/oxware-src` and runs the real installer.
