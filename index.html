Platform Özellikleri

Kurumsal Sanallaştırma için
İhtiyacınız Olan Her Şey

OXware Hypervisor, veri merkezleri ve bulut altyapıları için tasarlanmış, tam kapsamlı bir KVM yönetim çözümüdür.

⚡
KVM Donanım Hızlandırması
Native KVM sanallaştırması ile %95'e varan donanım performansı. CPU pinning, NUMA ve VirtIO sürücüleri dahil.
🌐
Web Tabanlı Yönetim
Herhangi bir tarayıcıdan HTTPS üzerinden güvenli erişim. Responsive tasarım ile mobil ve masaüstü desteği.
📸
Anlık Snapshot & Klonlama
Saniyeler içinde VM durumunu kaydedin, geri yükleyin veya klonlayın. Sıfır kesinti ile üretim ortamı yönetimi.
🖥️
noVNC Konsol Erişimi
Plugin gerektirmeden tarayıcı üzerinden tam grafik konsol. Şifreli WebSocket bağlantısı ile güvenli erişim.
🔌
PCIe Passthrough
GPU, NIC ve özel donanımları VM'lere doğrudan bağlayın. IOMMU desteği ile izole edilmiş donanım erişimi.
📡
REST API
JWT kimlik doğrulamalı tam REST API. WiseCP, WHMCS ve özel otomasyon sistemleriyle entegrasyon.
🔐
İki Faktörlü Kimlik Doğrulama
TOTP tabanlı 2FA ile hesap güvenliği. QR kod ile kolay kurulum, tüm authenticator uygulamalarıyla uyumlu.
📊
Gerçek Zamanlı İzleme
CPU, RAM, disk ve ağ kullanımını WebSocket üzerinden canlı olarak izleyin. Grafik tabanlı kaynak analizi.
💿
ISO Yönetimi
Sunucuya ISO yükleyin, CD/DVD olarak VM'lere bağlayın. Desteklenen tüm işletim sistemleriyle kurulum.

Güvenlik

Kurumsal Güvenlik
Standartları

OXware Hypervisor sıfırdan güvenlik odaklı tasarlanmıştır. Çok katmanlı koruma ve şifreleme dahil.

🔒
TLS 1.2+ Zorunlu Şifreleme
Tüm bağlantılar TLS üzerinden şifrelenir. HTTP → HTTPS otomatik yönlendirme. Öz-imzalı sertifika veya Let's Encrypt desteği.
📲
TOTP İki Faktörlü Doğrulama
Google Authenticator, Authy ve uyumlu tüm TOTP uygulamalarıyla çalışır. Başlangıç kodu yalnızca bir kez gösterilir.
🔑
PBKDF2 Şifre Hashleme
Şifreler 256.000 iterasyon PBKDF2-SHA256 ile hashlenir. Rainbow table saldırılarına karşı salt eklenir.
👤
Rol Tabanlı Erişim Kontrolü
admin ve user rolleri. API endpoint'leri rol denetimiyle korunur. Her işlem için yetki kontrolü.
🛡️
JWT Token Yönetimi
Kısa ömürlü JWT access token + refresh token mimarisi. Oturum sonlandırma ve token iptal mekanizması.
🔗
API Anahtarı Yönetimi
Programatik erişim için API anahtarı oluşturun, iptal edin. WiseCP ve WHMCS entegrasyonu için hazır.
Kurulum

4 Adımda Hazır

OXware Hypervisor grafiksel Calamares installer ile 5-15 dakika içinde kurulur.

1
ISO İndir
OXware-Hypervisor ISO dosyasını indirin (~1.5GB, amd64)
2
USB'ye Yaz
Rufus (Windows) veya dd komutu (Linux) ile USB'ye yazın
3
Grafiksel Kurulum
Calamares yüklenir: disk seç, kullanıcı oluştur, onayla. ~10 dakika.
4
Web Arayüzü Açık
https://<server-ip>:8006 adresinden yönetim paneline erişin
Clone ile otomatik kurulum
OXware kodlarını sunucunuza kopyalayarak kurabilirsiniz.
git clone https://github.com/ShinnAsukha/oxware-hypervisor /opt/oxware && sudo bash install.sh
