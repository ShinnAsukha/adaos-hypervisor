Everything you need to run a hypervisor

From bare-metal to VM in minutes. No licensing fees, no vendor lock-in.

VM Management

Full KVM/QEMU lifecycle — create, start, stop, pause, reboot, clone, and delete. Bulk operations, templates, CPU pinning, vCPU hot-plug, and scheduling.

Role-Based Access Control

Four built-in roles: administrator, operator, viewer, and vm-user. Assign specific VMs to vm-user accounts so tenants only see what they own.

VNC & SSH Console

Embedded noVNC console in a dedicated window with pointer lock, Ctrl+Alt+Del, and fullscreen. Web-based SSH terminal for direct shell access.

Monitoring & Alerts

Live CPU, RAM, disk I/O, and network metrics. Alert rules with Telegram, Discord, and email notifications. Anomaly detection and Prometheus endpoint.

Network Management

IP pool management (CIDR), NAT and bridge modes, per-VM QoS bandwidth limits, DNS watchdog, HAProxy integration, and nftables firewall per VM.

AI Assistant

Create VMs using natural language. Capacity forecasting predicts resource needs from historical trends. Auto-scaler adjusts VM resources based on load.

Built with
Python 3 Flask + SocketIO KVM / QEMU noVNC libvirt JWT Auth

Quick Start

Three commands and you're running.

# Clone the repository
git clone https://github.com/ShinnAsukha/oxware-hypervisor.git /opt/oxware-src

# Run the installer (requires root, Ubuntu 22.04 LTS)
cd /opt/oxware-src && sudo bash install.sh

# Open the web UI
https://<server-ip>:8006  # complete the setup wizard on first boot
