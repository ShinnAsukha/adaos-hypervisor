Özellikler

Her şey dahil. Tek platform.

VM yönetiminden ağ güvenliğine, AI tahminlemesinden Terraform entegrasyonuna kadar ihtiyacınız olan her şey.

🖥️

VM Yönetimi

KVM/QEMU tabanlı sanal makineleri oluştur, başlat, durdur, klonla, anlık görüntü al. SPICE/noVNC konsol desteği.

🛡️

nftables Güvenlik Duvarı

Web arayüzünden kural yönetimi. SSH port koruma, zincir yönetimi, policy ayarları. Otomatik SSH watchdog.

🤖

AI Kapasite Tahminleme

Claude AI ile kaynak kullanım tahmini. Anormallik tespiti, otomatik ölçekleme önerileri, akıllı izleme.

🌐

Ağ & SDN

OpenVSwitch entegrasyonu, VLAN yönetimi, network QoS, WireGuard VPN, HAProxy/Nginx load balancer.

💾

Depolama Yönetimi

Disk oluşturma, anlık görüntü, yedekleme, depolama migrasyonu. MinIO S3 entegrasyonu. LVM desteği.

🔑

Cloud-Init Desteği

NoCloud ISO ile otomatik VM yapılandırma. SSH key injection, kullanıcı oluşturma, ilk boot scripti.

📊

Gerçek Zamanlı İzleme

CPU, RAM, disk, ağ metrikleri. Performans geçmişi, alert kuralları, Suricata IDS/IPS entegrasyonu.

🔌

PCI / USB Passthrough

GPU ve USB cihazlarını doğrudan VM'e aktar. Web arayüzünden virsh hostdev yönetimi.

🏗️

Terraform Provider

Infrastructure as Code desteği. oxware_vm resource ile VM'leri kod ile yönet. Go tabanlı resmi provider.

👤

Çok Kullanıcı & RBAC

JWT kimlik doğrulama, TOTP 2FA, LDAP entegrasyonu, rol bazlı erişim kontrolü, oturum yönetimi.

📋

API & Webhook

300+ REST endpoint, OpenAPI dokümantasyonu, webhook desteği, API key yönetimi, event log sistemi.

🔧

CLI Araçları

ox komutu ile terminal kontrolü. oxupdate ile tek komutla güncelleme.

Kurulum

Dakikalar içinde çalışır.

Ubuntu 20.04+ veya Debian 11+ üzerinde tek komutla tam kurulum.

01

Sunucuyu Hazırla

Ubuntu 22.04 LTS önerilir. Minimum 2 GB RAM, 15 GB disk, CPU sanallaştırma (VT-x/AMD-V) aktif.

02

Kurulum Scriptini Çalıştır

Tek komut: KVM, libvirt, Python ortamı, SSL sertifikası, systemd servisi otomatik kurulur.

03

Web UI'ya Giriş Yap

https://SUNUCU_IP:8006 adresine git. Admin hesabı oluştur, sistemi kullanmaya başla.

04

VM Oluştur

ISO yükle, VM oluştur, cloud-init yapılandır. Dakikalar içinde sanal makinen hazır.
