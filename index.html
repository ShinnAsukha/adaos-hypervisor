Enterprise Features, Zero Cost

Everything you need to run production workloads.

VM Lifecycle Management

Create, start, stop, reboot, clone, and snapshot VMs with full KVM power. Bulk operations, CPU pinning, vCPU hot-plug, scheduling, and template-based provisioning.

noVNC Console

Browser-based VNC and serial console — no client needed. Pointer lock, Ctrl+Alt+Del, clipboard support, fullscreen, and SPICE for high-performance sessions.

RBAC & Multi-User

Role-based access with four built-in roles: admin, operator, vm-user, and viewer. Assign specific VMs to tenants so they only see and manage what they own.

Cloud-Init & Auto-Provision

Automated VM configuration at first boot: SSH key injection, static IP setup, hostname assignment, and network configuration — no manual intervention required.

IPAM & Networking

IP address management with CIDR pools, WireGuard VPN, VLAN tagging, SDN via Open vSwitch, HAProxy load balancer, per-VM QoS, and nftables firewall.

AI Assistant

Built-in AI for natural-language VM creation, capacity forecasting, anomaly detection, and workload analysis. Predict resource exhaustion before it impacts production.

Cluster & DRS

Distributed Resource Scheduler auto-balances VMs across hosts by CPU/RAM load. EVC CPU compatibility for live migration across CPU generations. Affinity/anti-affinity rules, NUMA-aware scheduling, maintenance mode evacuation.

Security & Compliance

vTPM 2.0 (Windows 11/BitLocker), AMD SEV/Intel TDX confidential VMs, LUKS2 disk encryption, automated CIS/NIST/PCI-DSS/HIPAA/ISO 27001 compliance scanner, DLP engine, forensics, SAML/OIDC SSO, MFA per role.

Disaster Recovery

3-2-1 backup automation, app-consistent snapshots (fsfreeze), backup mount+boot verification, cross-site async/sync replication. RPO/RTO SLA tracking, automated DR runbooks, one-click failover.

Multi-Tenancy

Hard tenant isolation with per-tenant vCPU/RAM/disk quotas, self-service portal, chargeback/showback billing engine (€/$/TRY), 6-template service catalog, token-bucket rate limiting per tenant.

Kubernetes & Cloud

Kubernetes CSI driver (csi.oxware.io), OxwareVM CRD Operator, KubeVirt import/export, GitOps (ArgoCD/Flux), Pulumi IaC generation, workload mobility to AWS AMI / Azure VHD / GCP.

Modern Workloads

Firecracker microVM (125ms boot), Kata Containers runtime, WASM module execution (wasmtime/wasmedge), edge deployment mode. OPA/Rego policy-as-code, CloudEvents v1.0, workflow automation engine.

IaC & Terraform

Official Terraform provider: oxware_vm, oxware_network, oxware_storage_pool resources + data sources. Full REST API (~190 endpoints) with OpenAPI spec auto-generated at /api/docs.

Open Source · MIT

Full source on GitHub. No vendor lock-in, no subscriptions, no fees. Self-hosted on your own infrastructure forever. Community-driven development with enterprise features baked in.

Quick Start

Three commands and you're running.

# Clone the repository
git clone https://github.com/ShinnAsukha/oxware-hypervisor.git /opt/oxware-src

# Run the installer (requires root, Ubuntu 22.04 LTS)
cd /opt/oxware-src && sudo bash install.sh

# Open the web UI
https://<server-ip>:8006  # complete the setup wizard on first boot
