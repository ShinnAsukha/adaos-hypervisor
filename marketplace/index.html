Curated extensions for OXware.

Plugins, templates, themes, and integrations — hand-selected by the maintainers for quality, security, and compatibility.

Curated catalog — maintainer-reviewed only

Maintainer-curated catalog

All entries are reviewed and added by the OXware maintainers. There is no public submission portal — this ensures every extension meets quality and security standards before it reaches your cluster. Suggest an extension via GitHub Discussions.

Plugin
hello-world
Minimal reference plugin. Adds a "Hello World" panel tab and a single REST endpoint. Use as a starting point for your own plugin.

Plugin
telegram-notifier
Push VM lifecycle events, alerts, and anomaly triggers to a Telegram bot. Configurable per-event type with message templates.
oxware-team v1.2.1
Plugin
discord-console
Mirror the OXware event log to a Discord channel. Supports webhook and bot token modes. Rich embeds with VM status colours.
oxware-team v1.1.0
Plugin
prometheus-exporter
Exposes OXware VM metrics on /metrics in Prometheus text format. CPU, RAM, disk I/O, network rx/tx per VM. Scrape directly with Prometheus or VictoriaMetrics.
oxware-team v2.0.0
Plugin
pagerduty
Creates and resolves PagerDuty incidents from OXware anomaly events. Deduplicates on vm_id + anomaly_type to avoid alert storms.
oxware-team v1.0.3
Plugin
slack-notifier
Posts VM events, health alerts, and runbook executions to a Slack channel via incoming webhook or bot token. Supports per-channel routing by VM tag.
oxware-team v1.3.0
Template
wordpress-stack
Two-VM stack: Ubuntu 22.04 with Apache, PHP 8.2, MySQL 8. WordPress installed and configured. Ready to serve in under 5 minutes.
oxware-team v1.1.0
Template
k3s-cluster
Three-node k3s cluster on Ubuntu 22.04. One control-plane, two agents. Networking via Flannel. Kubeconfig exported automatically.
oxware-team v2.0.1
Template
monitoring-stack
Prometheus + Grafana + Alertmanager on a single VM. Pre-configured dashboards for OXware VM metrics. Scrapes the prometheus-exporter plugin automatically.
oxware-team v1.5.0
Template
mail-server
Postfix + Dovecot + Roundcube on Debian 12. DKIM, SPF, and DMARC pre-configured. Self-signed TLS on install; swap in Let's Encrypt post-deploy.
oxware-team v1.0.0
Template
wireguard-vpn
WireGuard VPN gateway on Ubuntu 22.04 with nftables masquerade. Generates peer configs on first boot. Web UI via wg-easy bundled.

Theme
vsphere-look
vSphere-inspired colour scheme for the OXware panel. Familiar teal-grey palette for VMware veterans migrating to OXware. Light and dark variants included.

backblaze-b2
Off-site backup target using Backblaze B2 object storage. Streams encrypted OXware backup archives directly to a B2 bucket. Lifecycle rules configurable from the OXware UI.
